# Diabetes Prediction Using Machine Learning

## Overview
A machine learning project that predicts diabetes outcomes using medical diagnostic data. It compares multiple classification algorithms and evaluates their performance.

## Technologies Used
- Python
- Pandas and NumPy
- Matplotlib and Seaborn
- Scikit-learn
- Joblib

## Machine Learning Models
1. Logistic Regression
2. Support Vector Machine (SVM)
3. Random Forest Classifier

## Project Workflow
- Data exploration and preprocessing
- Handling invalid zero values in selected medical features
- Train-test split and feature scaling
- Model training and comparison
- Evaluation using accuracy, precision, recall, F1-score, and ROC-AUC
- Confusion matrix, ROC curve, and feature-importance analysis

## Dataset
The project uses the Pima Indians Diabetes dataset, containing medical measurements and a binary outcome label.

## Model Evaluation
The models are compared using classification metrics and cross-validation. Actual results are available in `model_comparison.csv`.

## Limitations
This project is for educational purposes only. Its predictions are not a medical diagnosis and should not be used to make healthcare decisions.
